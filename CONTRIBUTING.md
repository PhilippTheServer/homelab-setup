# Contributing

This repository is a snapshot of a private repository, published from time to time. Nothing
is developed here directly.

- **Issues** are welcome: bugs, questions, ideas.
- **Pull requests** are welcome too, but they are not merged here. An accepted change is
  applied to the private repository and arrives with the next snapshot; the pull request is
  then closed with a pointer to it. Keep them small and say why.
- **Security problems** go to philipp.lehmann@gruppe.ai, not into an issue.

By contributing you agree that your contribution is licensed under the [MIT License](LICENSE)
and that you follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Some hostnames, addresses and names are replaced with placeholders such as `example.com`.
That is deliberate, not a bug.
