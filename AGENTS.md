# AGENTS.md — homelab

## Documentation

This repository documents only the homelab mini PC — see `README.md`, `docs/` and each role's
`README.md`, and `CLAUDE.md` for the rules. All documentation about **atlas** (the GPU node, its
VMs and every repository running on it) lives in the atlas repository,
[PhilippTheServer/atlas](https://github.com/PhilippTheServer/atlas), vendored here as a git
submodule at `docs/atlas`; run `git submodule update --init` if it is empty. Never write atlas
documentation in this repository.
