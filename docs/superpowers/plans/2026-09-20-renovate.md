# Renovate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Renovate runs daily from GitHub Actions and opens one PR per dependency when a newer version exists.

**Architecture:** A custom regex manager reads `# renovate:` annotation comments in `ansible/group_vars/all/vars.yml`, where this repo's real image pins live (the compose files are `.j2` templates that only reference variables). Three built-in managers cover `requirements.yml`, `requirements.txt` and the workflow files. A coverage check runs Renovate's local extract and fails if any pin is invisible to it.

**Tech Stack:** Renovate 41 (official container), GitHub Actions, Python 3 + `uv`, Ansible.

**Spec:** `docs/superpowers/specs/2026-09-20-renovate-design.md` · **Issue:** #103

## Global Constraints

- **Renovate runs as a container, never via `npx`.** The control node has Node 26; Renovate 41 supports `^22.13.0 || ^24.10.0` and exits with `Unsupported node environment detected`. Pin `ghcr.io/renovatebot/renovate:41` — verified working.
- **Renovate version is pinned in exactly one place:** `RENOVATE_IMAGE` in `scripts/check-renovate-coverage.py`. The workflow reads it from there. No second copy.
- **Bind-mounted repo needs git ownership set** or Renovate logs `fatal: detected dubious ownership`. Pass `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=safe.directory GIT_CONFIG_VALUE_0=/repo`.
- **Never write a secret to a file.** The PAT is a GitHub Actions secret named `RENOVATE_TOKEN`, set outside this repo. No `vault_*` mapping (spec §Authentication).
- **Python:** `uv`, never `pip`. `ruff check` and `ruff format` must both pass.
- **No inline comments** unless the *why* is non-obvious.
- **Four variables are never annotated:** `gym_bro_version`, `daily_version`, `library_version` (self-built Harbor images), `metube_version` (deliberately `latest`).
- **Docs change in the same commit as the code**, never after.

### Task 1: Coverage check script

The check must exist and **fail** before any Renovate config does — that is what makes it verification rather than decoration.

**Files:**
- Create: `scripts/check-renovate-coverage.py`

**Interfaces:**
- Produces: `RENOVATE_IMAGE` constant, read by `.github/workflows/renovate.yml` in Task 4 via `grep`.

- [ ] **Step 1: Write the script**

```python
#!/usr/bin/env python3
"""Fail if a version pin in group_vars is invisible to Renovate.

Runs Renovate's local extract and compares the `*_version` keys it matched
against the keys actually present in the vars file. A pin that is neither
extracted nor explicitly excluded is a silent update hole: that service never
gets a Renovate PR and nothing else would ever surface it.
"""

import json
import re
import subprocess
import sys
from pathlib import Path

REPO = Path(__file__).resolve().parent.parent
VARS = REPO / "ansible" / "group_vars" / "all" / "vars.yml"

RENOVATE_IMAGE = "ghcr.io/renovatebot/renovate:41"

EXCLUDED = {
    "gym_bro_version": "self-built Harbor image, bumped to publish a build",
    "daily_version": "self-built Harbor image, bumped to publish a build",
    "library_version": "self-built Harbor image, bumped to publish a build",
    "metube_version": "deliberately latest: a yt-dlp wrapper rots when pinned",
}

VERSION_KEY = re.compile(r"^([a-z0-9_]+_version):", re.MULTILINE)


def pins_in_vars_file() -> set[str]:
    return set(VERSION_KEY.findall(VARS.read_text()))


def replace_strings(node):
    """Yield every `replaceString` in Renovate's extract output.

    Walking the structure matters: these values contain real newlines, and
    matching against a re-serialised copy would capture the `n` of the escaped
    `\\n` as part of the variable name.
    """
    if isinstance(node, dict):
        for key, value in node.items():
            if key == "replaceString" and isinstance(value, str):
                yield value
            else:
                yield from replace_strings(value)
    elif isinstance(node, list):
        for item in node:
            yield from replace_strings(item)


def pins_renovate_extracted() -> set[str]:
    proc = subprocess.run(
        [
            "docker", "run", "--rm",
            "-v", f"{REPO}:/repo", "-w", "/repo",
            "-e", "LOG_LEVEL=info",
            "-e", "LOG_FORMAT=json",
            "-e", "RENOVATE_CONFIG_FILE=/repo/renovate.json5",
            "-e", "GIT_CONFIG_COUNT=1",
            "-e", "GIT_CONFIG_KEY_0=safe.directory",
            "-e", "GIT_CONFIG_VALUE_0=/repo",
            RENOVATE_IMAGE,
            "renovate", "--platform=local", "--dry-run=extract",
        ],
        capture_output=True,
        text=True,
    )
    if proc.returncode != 0:
        sys.exit(f"renovate extract failed ({proc.returncode}):\n{proc.stderr[-2000:]}")

    found = set()
    for line in proc.stdout.splitlines():
        try:
            record = json.loads(line)
        except json.JSONDecodeError:
            continue
        for replaced in replace_strings(record):
            found.update(VERSION_KEY.findall(replaced))
    return found


def main() -> int:
    present = pins_in_vars_file()
    extracted = pins_renovate_extracted()

    if not extracted:
        print("FAIL: renovate extracted no version pins at all.")
        print("      Is renovate.json5 present and is the custom manager matching?")
        return 1

    missing = sorted(present - extracted - set(EXCLUDED))
    leaked = sorted(extracted & set(EXCLUDED))

    for key in missing:
        print(f"FAIL: {key} is not extracted by Renovate and is not excluded.")
        print("      Add a '# renovate:' annotation above it, or add it to EXCLUDED.")
    for key in leaked:
        print(f"FAIL: {key} is excluded ({EXCLUDED[key]}) but Renovate extracted it.")
        print("      Remove its '# renovate:' annotation.")

    if missing or leaked:
        return 1

    print(f"OK: {len(present - set(EXCLUDED))} pins tracked, {len(EXCLUDED)} excluded.")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 1: Write `renovate.json5`**

The `matchStrings` regex below is verified working — it extracted all 7 test pins and correctly ignored `gitlab_homepage_user_id`, `gym_bro_version` and `metube_version`.

```json5
{
  $schema: "https://docs.renovatebot.com/renovate-schema.json",
  extends: ["config:recommended"],

  // Image pins live in group_vars as Ansible variables, not in the compose
  // files — those are .j2 templates that only reference the variables. No
  // built-in manager reads group_vars, so the annotation comments are what
  // makes them visible.
  customManagers: [
    {
      customType: "regex",
      description: "Service version pins in group_vars",
      managerFilePatterns: ["/^ansible/group_vars/all/vars\\.yml$/"],
      matchStrings: [
        "# renovate: datasource=(?<datasource>[a-z-]+?) depName=(?<depName>[^\\s]+?)(?: versioning=(?<versioning>[^\\s]+?))?\\s+[a-z0-9_]+?_version:\\s*[\"']?(?<currentValue>[^\"'\\s]+)[\"']?\\s",
      ],
    },
  ],

  // One PR per dependency: one PR maps to one `--tags <role>` deploy, so a bad
  // bump is reviewed, deployed and reverted in isolation.
  separateMinorPatch: true,
  prConcurrentLimit: 10,
  prHourlyLimit: 0,
  // Timing lives in the Actions cron alone. A schedule here would be a second
  // source of truth that drifts.
  schedule: ["at any time"],

  packageRules: [
    {
      matchUpdateTypes: ["major"],
      labels: ["renovate", "major"],
    },
    {
      matchUpdateTypes: ["minor", "patch"],
      labels: ["renovate"],
    },
  ],
}
```

- [ ] **Step 1: Write `.github/workflows/renovate.yml`**

```yaml
---
name: Renovate

on:
  schedule:
    # Daily at 05:17 UTC. Off the hour on purpose: GitHub delays jobs queued on
    # the hour, when everyone else's cron fires.
    - cron: "17 5 * * *"
  workflow_dispatch:
    inputs:
      logLevel:
        description: "Renovate log level"
        type: choice
        default: info
        options: [info, debug]

permissions:
  contents: read

jobs:
  renovate:
    name: Renovate
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6

      - name: Read the pinned Renovate version
        id: version
        run: |
          image=$(grep -oP 'RENOVATE_IMAGE = "\K[^"]+' scripts/check-renovate-coverage.py)
          echo "renovate=${image##*:}" >> "$GITHUB_OUTPUT"

      - uses: renovatebot/github-action@v46
        with:
          configurationFile: renovate.json5
          renovate-version: ${{ steps.version.outputs.renovate }}
          token: ${{ secrets.RENOVATE_TOKEN }}
        env:
          LOG_LEVEL: ${{ inputs.logLevel || 'info' }}
          RENOVATE_REPOSITORIES: ${{ github.repository }}
          RENOVATE_PLATFORM: github
```

`permissions: contents: read` is correct and not a mistake: Renovate authenticates with `RENOVATE_TOKEN`, not the job's `GITHUB_TOKEN`, so the job token needs nothing beyond checkout.
